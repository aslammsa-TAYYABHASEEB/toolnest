# PDF to Excel construction

- **Classification:** ToolNest custom / flagship.
- **Primary silhouette:** a source document feeds visually into an overlapping structured grid.
- **Semantic modifier:** the grid is deliberately neutral--no Microsoft mark, spreadsheet letter, or branded colour.
- **Family grammar:** 24x24 viewBox, 2px centered stroke, round caps and joins, `fill="none"`, `stroke="currentColor"`.
- **Small-size decision:** the grid uses three columns and two rows, the minimum structure that still reads as a table at 20px.
- **Identity cue:** custom ToolNest transformation icons may use a restrained overlap between source object and result structure.
